# ブスコハンター（Busko Hunter）

Minecraft Java 版用の、モンハン風ボス討伐 MOD です。
集会所でクエストを受注し、食事と装備で準備して出発し、広いフィールドで大型モンスター「ブスコ」たちを探して狩ります。
最大 4 人のマルチプレイに対応しています。

---

## 動作環境

| 項目 | バージョン |
|---|---|
| Minecraft Java Edition | 26.3 |
| Minecraft Forge | 66.1.0 以上（26.3 用） |

マルチプレイで遊ぶ場合は、**サーバーと全員のクライアントの両方**にこの MOD を入れてください。

## 導入方法

1. [Forge 公式サイト](https://files.minecraftforge.net/) から **Minecraft 26.3 用の Forge インストーラー** をダウンロードして実行し、「Install client」でインストールします。
2. このリポジトリの **Releases**（「latest」）から `buskohunter-1.0.0.jar` をダウンロードします。
3. `.minecraft/mods` フォルダ（Windows は `%appdata%\.minecraft\mods`）に入れます。フォルダが無ければ作ってください。
4. Minecraft ランチャーで「forge 26.3」の起動構成を選んで起動します。
5. ワールドに入ると「ハンターノート」が 1 冊もらえます。右クリックで集会所へ行けます。

> ワールドを作る／開くときに「実験的な設定を使用しています」という警告が出ることがあります。これは MOD が集会所とフィールド用のディメンションを追加しているためです。「I Know What I'm Doing!（理解しています）」を押せば遊べます（一度押せば、そのワールドでは次から出ません）。

## 自分でビルドする場合

JDK 25 を入れて、このフォルダで `gradlew build`（Mac/Linux は `./gradlew build`）を実行すると `build/libs/buskohunter-1.0.0.jar` ができます。
GitHub に push すると、GitHub Actions が自動でビルドして Releases に jar を置きます。

## 遊び方の流れ

1. **集会所へ行く**：ハンターノートを右クリック（または `/bh hub`）。
   集会所は専用のディメンションに自動で建ちます。サバイバルの人は集会所とフィールドでは自動的にアドベンチャーモードになり、元の世界に戻ると元に戻ります。
2. **クエスト受注**：北の「クエストカウンター」で受注。ほかの人が受注したクエストにも参加できます（1 クエスト最大 4 人）。
3. **準備**
   - 西の「装備ボックス」：14 種の武器 × 10 属性シリーズ、6 種の防具シリーズから選びます。武器は集めるのではなく、最初から全シリーズを選べます。
   - 東の「ブスコ食堂」：食事（1 クエストに 1 回）。体力・スタミナ・攻撃・防御・属性耐性・ネコ飯スキルが付きます。
   - 西の「アイテムボックス」：持ち込むアイテムの数を決めます。
4. **出発**：南の「出発ゲート」。参加者全員がフィールドのベースキャンプへ移動します。
5. **狩猟**
   - キャンプの「支給品ボックス」でアイテムを受け取れます。「ベッド」で体力・スタミナが全回復します。
   - フィールドにはエリア 1〜8 と巣があります。モンスターは 40 ブロック以内に近づくと発見扱いになり、マップに表示されます（ペイントボールでも表示）。
   - モンスターは一定時間戦うか、ダメージがたまるとエリアを移動します。弱ると足を引きずるようになり、さらに弱ると巣へ移動して眠り、少しずつ体力を回復します。
   - 怒り状態・疲労状態（よだれ）・部位破壊・ダウン・気絶（スタン）・状態異常（毒・麻痺・睡眠・爆破）があります。
   - 弱ったモンスター（体力 25% 以下で「捕獲可能」表示）は、罠にかけて捕獲用麻酔玉を当てると捕獲できます。
   - 3 回力尽きるか、制限時間（50 分）を過ぎるとクエスト失敗です。力尽きるとベースキャンプに戻されます。
6. **クリア**：討伐後、倒したモンスターを右クリックすると剥ぎ取りができます。約 25 秒後に集会所へ戻り、報酬画面で HR ポイントと報酬金を受け取ります。
7. 集会所南西の「帰還ゲート」で元の世界に戻れます（`/bh exit` でも可）。

集会所の南東には「訓練場」があり、訓練用ブスコ人形で技とダメージの確認ができます。

## 操作

| キー | 動作 |
|---|---|
| 左クリック | 攻撃 A |
| 右クリック | 攻撃 B |
| R | 特殊アクション |
| Shift／ジャンプを素早く 2 回 | 回避（移動キーの方向へ。ライトボウガンはステップ、鬼人化中の双剣は鬼人回避）。武器を持っている間はしゃがみの代わりになります |
| 右クリック長押し | ガード（大剣・片手剣・ランス・ガンランス・チャージアックス）。ガード中の左・R で派生技 |
| 右クリックを押したまま左／R | 太刀・狩猟笛・スラッシュアックス・ボウガンの派生技 |
| H | ハンターメニュー（クエスト状況・マップ・遊び方・リタイア） |
| V | 狩猟用の視点切り替え（クエスト中は自動で三人称になります） |

キーはオプションの「操作設定 → ブスコハンター」で変更できます。
回復薬などの道具は、ホットバーで持ち替えて右クリックで使います。
回避や一部の技（溜め・鬼人化など）はスタミナを使います。クエスト中は走るとスタミナが減ります。

### 武器（14 種）

| 武器 | 主な操作 |
|---|---|
| 大剣 | 左：縦斬り（長押しで溜め→強溜め→真溜め）／右：なぎ払い／R：タックル（スーパーアーマー・溜め段階継続）／右長押し：ガード |
| 太刀 | 左：縦斬り→突き→斬り上げ／右：踏み込み斬り／R：気刃斬り I→II→III→大回転（練気レベル上昇）／右を押したまま R：見切り斬り（カウンター）／右を押したまま左：気刃兜割 |
| 片手剣 | 左：斬り下ろし→横斬り→剣盾コンボ／右：回転斬り／R：盾攻撃→昇竜撃／右長押し：ガード |
| 双剣 | 左：二連斬り→返し斬り→車輪斬り／右：回転斬り／R：鬼人化 ON/OFF／鬼人化中の右：鬼人乱舞 |
| ハンマー | 左：縦振り 1→2→アッパー／右長押し：溜め（Lv1〜3）→離して溜め攻撃／R：回転攻撃→ホームラン |
| 狩猟笛 | 左・右・R で音符 1〜3／右を押したまま左：演奏（旋律効果） |
| ランス | 左：中段突き×3／右：上段突き×3／R：突進／右長押し：ガード／ガード中に左：カウンター突き |
| ガンランス | 左：突き→突き→斬り上げ→叩きつけ／右：砲撃／叩きつけ後の右：フルバースト／R：竜撃砲／右長押し：ガード／ガード中に R：リロード |
| スラッシュアックス | 斧と剣の 2 形態。R：変形斬り／剣モードで右を押したまま R：属性解放突き |
| チャージアックス | 剣：斬り・突進斬り・右長押しでガード・ビンにチャージ／ガード中に左：斧へ変形／斧：叩きつけ・属性解放斬り I→II→高出力 |
| 操虫棍 | 左：斬り上げ→袈裟斬り→回転斬り／右：跳躍（空中攻撃）／R：猟虫（頭=赤・胴=橙・脚=白のエキス） |
| ライトボウガン | 左：通常弾／右：速射／R：リロード／右を押したまま R：弾種切替 |
| ヘビィボウガン | 左：射撃／右長押し：機関竜弾／R：リロード／右を押したまま R：弾種切替 |
| 弓 | 左長押し：溜め→射撃（Lv1〜3）／右：剛射／R：竜の一矢（貫通） |

武器の属性シリーズ（各武器共通）：**火・水・雷・氷・龍・毒・麻痺・睡眠・爆破・ブスコバ**
近接武器には切れ味（ゲージ）があり、砥石で回復します。

## クエスト（17 個）

- **下位**（HR1〜）：酒池肉林の宴／オアシスの微笑み／地獄の釜の底／電脳に踊れ／【緊急】天上の王
- **上位**（HR3〜）：声劇の夜は終わらない／潤いすぎた砂原／造形破壊神／POSE YOUR GAME／王は二度降臨する／【大連続狩猟】天国と地獄／ブスコバ生け捕り作戦
- **G級**（HR7〜）：極・酒池肉林／極・オアシスの笑み／【大連続狩猟】電脳と砂原／極・凡百の突起物／【最終決戦】ブスコ五獣集結（5 頭連続）

HR はクエスト報酬のポイント 400 ごとに 1 上がります。参加人数に応じてモンスターの体力が増えます。

## コマンド

|---|---|

## 中身について

- **BGM・効果音**：全 104 種（BGM 12 曲・効果音 92 種）。すべてプログラムで合成したオリジナルです。集会所・準備・フィールド・モンスターごとの戦闘曲 5 曲・クリア／失敗ジングル・報酬画面の曲があり、場面に合わせてクロスフェードで切り替わります。BGM の音量はゲームの「音楽」設定に従います。
- **モーション**：プレイヤーの腕・体・脚を武器と技ごとに動かす独自アニメーション（回避の前転、溜め、武器ごとの構えなど）。マルチプレイでは他の人の動きも同期されます。
- **UI**：体力・スタミナ・切れ味・武器ゲージ・状態アイコン・制限時間・ミニマップ・パーティ表示・ダメージ数値・通知バナー。クエスト中はバニラの体力・満腹度バーが隠れます。
- **モンスターの肖像画**（クエストカウンターに表示）は、提供された 5 枚の画像を縮小して作りました。
- フィールドは Minecraft の地形生成を使い、クエストごとに離れた区画を割り当てるので、複数のパーティが同時に別のクエストを遊べます。

## ファイル構成

```
src/main/java/com/buskohunter/     サーバー・共通（クエスト、モンスター AI、武器の当たり判定、通信）
src/client/java/com/buskohunter/   クライアント（HUD、画面、アニメーション、モデル、BGM）
src/main/resources/assets/          テクスチャ・音・モデル・言語ファイル（日本語／英語）
src/main/resources/data/            ディメンション（集会所と 5 つのフィールド）・ダメージタイプ
tools/                              素材の生成スクリプト（Python）。BGM・効果音の合成（audio/）、モンスターのモデルとテクスチャ（models/）、リソース JSON（gen_resources.py）など
```
`tools/` の中のスクリプトは制作時の環境のパス（`/home/claude/...`）を前提にしているので、使う場合はパスを書き換えてください。MOD のビルドには不要です。
